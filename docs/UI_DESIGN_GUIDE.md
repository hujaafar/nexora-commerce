# Interface and motion

Nexora uses charcoal surfaces, cobalt actions, light blue type accents and a
single cinematic product composition. The storefront presents product search,
inventory, bag, orders and seller tools as one visual system.

The ScrollCraft runtime comes from the user's Neo4flix project. Desktop scroll
progress drives a pinned hero zoom and a spreading three-card composition.
Product cards enter with a short stagger and respond to hover. Compact screens
and reduced-motion preferences use a direct vertical layout. Keyboard focus
brings a story card to the front; section links retain their real anchor targets.

The Angular directive owns and releases runtime listeners, observers, frames,
timers and pinning styles when a route closes. Vendor licensing and the local
adaptation are documented in THIRD_PARTY_NOTICES.md.

Loading and failed searches have separate states. A version counter prevents a
slower previous search from replacing the latest results. All transactions use
the actual service APIs; the frontend is not backed by a local-storage demo.

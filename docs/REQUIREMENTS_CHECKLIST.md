# BUY-01 requirements checklist

This checklist mirrors the assignment and is updated as the implementation grows.

- [ ] User, Product, and Media Spring Boot microservices
- [ ] Gateway and Eureka discovery service
- [ ] MongoDB persistence with separate service databases
- [ ] JWT login, BCrypt passwords, CLIENT and SELLER roles
- [ ] Ownership checks for product and media writes
- [ ] Public product listing and detail endpoints
- [ ] Image-only uploads, content sniffing, and a 2 MB limit
- [ ] Object storage rather than image bytes in MongoDB
- [ ] Kafka product/media domain events
- [ ] Health endpoints for every service
- [ ] Central validation and error responses
- [ ] Gateway CORS and downstream JWT verification
- [ ] Angular routes, guards, interceptors, and reactive forms
- [ ] Sign-in, sign-up, seller dashboard, catalog, profile, and media manager
- [ ] Responsive UI with inline validation and toast-style errors
- [ ] Docker Compose and one-command run scripts
- [ ] Automated backend and frontend tests
- [ ] HTTPS deployment guidance
- [ ] Comprehensive README and API examples
